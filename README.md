<summary><b>⚙️ Setup Notes (read this before pushing)</b></summary>
<br>

**1. Fix broken stats cards — self-host instead of using the shared demo**
The public `github-readme-stats.vercel.app` and `github-readme-activity-graph.vercel.app` servers are shared by thousands of profiles and frequently hit GitHub's 5,000-requests/hour API cap, which is why cards sometimes fail to load. Deploy your own free copy:
- Fork [anuraghazra/github-readme-stats](https://github.com/anuraghazra/github-readme-stats) → Vercel → "New Project" → import your fork → Deploy. Add a `GH_TOKEN` (a GitHub personal access token) in Vercel's environment variables. Then swap `github-readme-stats.vercel.app` in the README for your own `*.vercel.app` URL.
- Do the same for [ashutosh00710/github-readme-activity-graph](https://github.com/ashutosh00710/github-readme-activity-graph) if the activity graph also fails.
- The streak stats and trophy servers occasionally have the same issue; fork+redeploy the same way if needed: [streak-stats](https://github.com/DenverCoder1/github-readme-streak-stats), [trophy](https://github.com/ryo-ma/github-profile-trophy).

**2. Enable the snake and 3D contribution graph**
Two workflow files are included alongside this README: `.github/workflows/snake.yml` and `.github/workflows/profile-3d-contrib.yml`.
- Create a repo named exactly `AgileSecDev` (must match your username) and push this README plus the `.github/workflows/` folder into it.
- Go to the repo's **Actions** tab, enable workflows, and run each one manually once (`Run workflow`) — after that they regenerate automatically on schedule.
- The snake workflow pushes its SVGs to an `output` branch; the 3D contrib workflow commits its SVGs to `main`. The image URLs in this README already point to those locations.

**3. On "true" interactivity / 3D**
GitHub strips `<script>` tags and JS from README markdown, so a real playable game or a rotating WebGL model can't run inside the README itself — the snake and 3D-graph above are the closest equivalent, since they're auto-generated images rather than live code. If you want an actual interactive demo (e.g. a Three.js scene, a mini game), the usual move is to host it separately (GitHub Pages, Vercel, itch.io for game builds) and link to it here with a badge/screenshot — happy to help build one if you want it.

</details>
