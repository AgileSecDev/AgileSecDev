## 2. Add the 3D workflow

Create:

```text
.github/workflows/3d-contribution.yml
```

and put:

```yml
name: GitHub Profile 3D Contribution

on:
  schedule:
    - cron: "0 0 * * *"
  workflow_dispatch:

permissions:
  contents: write

jobs:
  build:
    runs-on: ubuntu-latest

    steps:
      - name: Checkout repository
        uses: actions/checkout@v6

      - name: Generate 3D contribution profile
        uses: yoshi389111/github-profile-3d-contrib@0.7.1
        env:
          GITHUB_TOKEN: ${{ secrets.GITHUB_TOKEN }}
          USERNAME: AgileSecDev

      - name: Commit generated files
        run: |
          git config user.name "github-actions"
          git config user.email "github-actions@github.com"

          git add -A

          if git diff --cached --quiet; then
            echo "No changes to commit."
          else
            git commit -m "chore: update 3D contribution profile"
            git push
          fi
```

The generated files should appear under `profile-3d-contrib/`; the action's documented examples use this workflow pattern and version `0.7.1`. ([GitHub][1])

```text
    ├── profile-gitblock.svg
    └── ...
```

### One important point

Don't manually create `profile-night-view.svg`. **GitHub Actions generates the 3D files** after you run the workflow. The workflow files themselves belong under `.github/workflows/`. ([GitHub Docs][2])

For the **Contribution Snake**, you also need a separate Snake workflow if you want that section to actually generate its `output/...svg` files.

This overall version is intentionally **black + white + gray**, rather than mixing the green/blue/red styles from the reference profiles.
